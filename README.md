# สถานีตำรวจภูธรบางเสาธง · ป้องกันปราบปราม

ต้นแบบหน้าเว็บศูนย์สั่งการ 191: แผนที่สถานการณ์, รายการเหตุล่าสุด, นาฬิกาอาชญากรรม 24 ชม., เปรียบเทียบช่วงเวลา, บันทึกเหตุ และตัวกรอง/รายงาน

## เปิดใช้งานด้วย GitHub Pages
1. Settings → Pages
2. Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save
3. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## ข้อควรทราบ
- แผนที่ใช้ Leaflet + OpenStreetMap เส้นเขตตรวจและจุดตรวจมาจาก `area.js` (แปลงจาก KML ของ Google My Maps) ถ้าแก้แผนที่ต้นฉบับ ต้องส่งออก KML แล้วแปลงใหม่
- ข้อมูลเหตุเป็นข้อมูลจำลอง สุ่มภายในเขตรับผิดชอบจริง
- ไม่มีหน้าเข้าสู่ระบบ ผู้ที่มีลิงก์เปิดดูได้ทันที
- เหตุที่บันทึกใหม่เก็บใน localStorage ของเบราว์เซอร์แต่ละเครื่อง

# ระบบรายงานเหตุ 191 สมุทรปราการ

ต้นแบบหน้าเว็บศูนย์สั่งการ 191: เข้าสู่ระบบ, แผนที่สถานการณ์, รายการเหตุล่าสุด, นาฬิกาอาชญากรรม 24 ชม., เปรียบเทียบช่วงเวลา, บันทึกเหตุ และตัวกรอง/รายงาน

## เปิดใช้งานด้วย GitHub Pages
1. Settings → Pages
2. Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save
3. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## บัญชีทดลอง
- `admin` / `191admin` (ผู้ดูแลระบบ)
- `officer` / `191officer` (เจ้าหน้าที่)

## ข้อควรทราบ
- ข้อมูลเหตุเป็นข้อมูลจำลอง และแผนที่เป็นแผนที่จำลองเขตอำเภอ
- การเข้าสู่ระบบตรวจรหัสในเบราว์เซอร์ จึงเป็นเพียงการสาธิต ไม่ใช่การป้องกันข้อมูลจริง
- เหตุที่บันทึกใหม่เก็บใน localStorage ของเบราว์เซอร์แต่ละเครื่อง
